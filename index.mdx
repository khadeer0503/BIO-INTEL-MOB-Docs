# BIO-INTEL-MOB

Welcome to the documentation portal for the **Smart Urbanity VR** crowdsourcing platform.

The platform combines immersive city exploration, geolocated citizen proposals, street-level inspection workflows, object placement, and traffic/pedestrian simulation. The runtime stack includes Unity, OpenXR, Cesium, WordPress REST APIs, and SUMO.
