# Development & environment setup

Set up the Unity VR client and the Mintlify documentation site with the steps below.

## Unity VR development environment

### Prerequisites & versions

- Game Engine: Unity 6 LTS (Version `6000.0.x` or later recommended) with Universal Render Pipeline (URP).

- XR Runtime: OpenXR Plugin (`com.unity.xr.openxr`) and XR Interaction Toolkit (`com.unity.xr.interaction.toolkit` v3.x+).

- Geospatial Engine: Cesium for Unity (v1.12+).

- Traffic Simulator: Eclipse SUMO (v1.18.0+) with Python 3.10+ and TraCI bindings.

- Target Hardware: Meta Quest 2 / 3 / Pro (via Oculus Link / AirLink), HTC Vive Focus 3, or PC VR-tethered HMDs.

### Setup instructions

1. Clone the Repository:
   ```powershell
   git clone https://github.com/khadeer0503/CrowdSourcing_Virtual-Reality.git
   ```
2. Configure Cesium ion Token:
   - Navigate to Cesium > Cesium ion in the Unity Editor menu bar.
   - Connect your Cesium ion account or specify a project-level access token with permissions for *Google Photorealistic 3D Tiles*.
3. Configure SUMO Path:
   - Install SUMO on the host workstation.
   - Set the system environment variable `SUMO_HOME`:
     ```powershell
     [System.Environment]::SetEnvironmentVariable('SUMO_HOME', 'C:\Program Files (x86)\Eclipse\Sumo', 'User')
     ```
   - Verify that the `sumo` and `sumo-gui` binaries are accessible in your system `PATH`.
4. OpenXR Controller Bindings:
   - In Unity Editor, go to Project Settings > XR Plug-in Management > OpenXR.
   - Verify that interaction profiles are enabled for your target controllers (e.g., *Oculus Touch Controller Profile*, *HTC Vive Controller Profile*).

## Mintlify documentation setup

The documentation site uses Mintlify. Run it locally to preview changes with live reload.

### Prerequisites

- Node.js 20.17.0+ (LTS recommended)

- Git

- Global Mintlify CLI:
  ```powershell
  npm install -g mint@latest
  ```

### Local preview & validation

```powershell
# Navigate to documentation directory
cd "D:\CTLup\Unity_Projects\Documentation\BIO-INTEL-MOB-Docs"

# Start local hot-reloading development server
mint dev

# Validate documentation links and frontmatter
mint validate

# Generate and check the shared and per-pilot OpenAPI contracts
npm ci
npm run api:generate
npm run api:check
```

Preview the running site at [http://localhost:3000](http://localhost:3000).

## Publishing & deployment workflow

1. Branch Strategy: Commit updates to feature branches or `main`.
2. Continuous Deployment: Connect the repository to the Mintlify dashboard. Pushes to `main` trigger an automated build, linting, and deployment to the global edge CDN.
3. API Contract Verification: After editing a pilot URL or shared operation, run `npm run api:generate`, `npm run api:check`, and `mint validate` before committing the specifications. Refresh the deployment audit when checking live API behavior; see the [API maintenance workflow](/api-reference/overview#maintaining-the-api-reference).
